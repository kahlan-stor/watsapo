KM WhatsApp Manager
====================

كل ملفات المشروع موجودة مباشرة داخل هذا المجلد بدون مجلدات فرعية.

الملفات:
- main.py              البرنامج الرئيسي
- requirements.txt    المكتبات المطلوبة
- README.txt          تعليمات التشغيل

على Termux:
1) pip install -r requirements.txt
2) python main.py

ثم افتح:
http://127.0.0.1:5000

بعد ظهور QR:
WhatsApp Business > الأجهزة المرتبطة > ربط جهاز > مسح QR

المزايا الحالية:
- ربط غير رسمي عبر QR
- حفظ الجلسة بحسب دعم المكتبة
- استقبال المحادثات وحفظها
- واجهة الدردشات
- إرسال الرسائل
- إضافة/حذف ردود تلقائية
- عدة كلمات/عبارات لنفس الرد
- SQLite لحفظ المحادثات والردود

تنبيه:
هذا ربط غير رسمي وليس من Meta/WhatsApp، وقد يتغير أو يتوقف أو يؤدي إلى تقييد الحساب.
